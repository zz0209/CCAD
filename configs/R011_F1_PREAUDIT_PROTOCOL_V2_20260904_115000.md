# R011-F1 pre-audit protocol v2 — crossed C040 metric repair

Status: **LOCKED AND EXECUTION ENABLED; CALIBRATION/AUDIT UNREAD**

Supersedes only §5 of v1. Query construction, candidate universes, FCC ranks,
hard negatives, baselines, calibration gates, causal endpoint and audit boundary
remain unchanged. V1 probe artifacts remain immutable engineering/diagnostic
evidence and cannot be used as the FCC metric.

## Estimand and unit

The C040 hook metric targets the document-balanced discovery expectation

\[
M = \mathbb E_x[J_x^\top P_{\mathrm{sketch}}J_x],
\]

where `x` is a selected hook state and `J_x` maps a layer-5 residual
perturbation to the fixed signed next-logit sketch. A state is the repeated-
measure block; directions and output coordinates are not independent samples.

The v1 design used a different random direction at each state and therefore
identified the Gram of an average Jacobian rather than the average Jacobian
Gram. V2 crosses state and direction: every state receives exactly the same
complete orthonormal hook basis. For each direction, state output effects are
concatenated with equal `1/sqrt(n_states)` weight before ridge fitting. With a
complete basis, the fitted pullback is the requested mean state Jacobian Gram.

## Frozen design

- split: discovery only; calibration and audit files are forbidden;
- 32 states, selected by the existing content-hash/document-balanced rule;
- eligible states must have at least 16 causally visible tokens since sequence
  start or the most recent EOT token (`id=0`); future tokens are not inspected;
- 768 deterministic orthonormal shared directions, a complete layer-5 basis;
- central perturbation `+/- 0.01 × discovery hook RMS`;
- the same fixed 256-coordinate signed next-logit sketch used by v1;
- equal state weights; no response-based deletion, clipping or winsorization;
- ridge fraction `1e-4`, eigenvalue relative tolerance `1e-6`, trace normalized
  to 768;
- 24,576 state-direction probes / 49,152 variants in batches of 16;
- next-state residual remains the independent primary causal screen endpoint.

## Pre-compute and acceptance gates

Before model execution, deterministic tests must verify complete-basis
orthonormality, exact recovery of an average Gram for state-varying synthetic
Jacobians, invariance to balanced state duplication, and the input-only
boundary rule. The real artifact must additionally verify all frozen hashes,
32 unique states, one state per blocking document, the 16-token margin, complete
central pairs, finite effects, PSD/trace normalization and nonzero numerical
rank.

State influence is audited without changing the equal-weight estimand. Report
each state's unnormalized Jacobian-Gram trace share; require maximum share at
most 0.25 and effective state count `1/sum(share^2)` at least 8. Failure rejects
the query-agnostic C040 metric; it does not authorize dropping the state or
tuning these thresholds.

## Stopping rule

One formal v2 metric run is allowed. A code/environment failure may receive one
minimal fresh suffix that changes no scientific field. If the scientific gates
fail, causal-metric FCC is reported unavailable and Euclidean FCC remains the
mandatory primary relation metric; calibration/audit stay closed until the
rest of the frozen FCC implementation is complete. Passing this gate freezes
the v2 metric hash for the existing 40-query pre-audit FCC screen and does not
itself establish C1-FCC or C2-FCC.
